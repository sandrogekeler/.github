# Contributing

Thanks for helping. A few rules hold across sandrogekeler's repositories; a
repository's own CONTRIBUTING.md takes precedence where it has one.

- Open an issue before a large change, so the approach can be agreed first.
- One concern per pull request.
- Pull request titles are release-notes copy: imperative, sentence case, no
  trailing period.
- Label pull requests with one `type:` (`feature`, `bug`, `chore`, `docs`) and
  an `area:` label where the repository uses them.
- Do not commit secrets or generated output.

Security problems: see [SECURITY.md](SECURITY.md), not a public issue.
