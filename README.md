# sandrogekeler/.github

GitHub's **default community health files** for repositories owned by
`sandrogekeler`. GitHub shows these in any repo that has none of its own
([docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).
This repository must stay public for that to work.

- They apply only to repos owned by this account, not to `kollektiv-mc` repos.
- Issue and PR templates live in `.github/` here, as GitHub requires. A repo with
  its own `.github/ISSUE_TEMPLATE/` uses none of these issue templates.
- Repos created from [AllesSandro](https://github.com/sandrogekeler/AllesSandro)
  carry their own copies, so these are the fallback for everything else.

Workflows, agent docs and repo setup live in AllesSandro, not here: a `.github`
repo gives them no special behaviour on a personal account.
